## 📁 Strict File Architecture — Zero Subfolders

As strictly mandated, **every single file is located directly in the root directory**. Absolutely no subfolders (`src/`, `assets/`, `css/`, `js/`, `components/`, etc.) were created.

```text
Marketing Agency Dashboard/
│
├── index.html        # Semantic HTML5 Application (All 15 Views, Modals & Triggers)
├── style.css         # Deep Charcoal & Electric Violet SaaS Design System & Glassmorphism
├── script.js         # Reactive Core Engine: Canvas Graphs, State Machine & LocalStorage
├── favicon.svg       # Brand Vector Icon (High-Precision Markora Growth Monogram)
└── README.md         # Comprehensive Technical Architecture & Platform Guide
```

## 🚀 How to Run

1. Simply double-click **`index.html`** in Windows File Explorer or any desktop environment.
2. Alternatively, open with VS Code and start **Live Server** or run directly in any modern browser.
3. **Zero build steps. Zero npm packages. Zero external CDN dependencies.** 100% offline-functional out of the box!

## 🌟 Core Functional Architecture & Key Features

### 1. 🧭 Navigation & Global Executive Cockpit
* **Collapsible Sidebar**: 15 distinct navigation views with active states, glow indicators, unread counters, and mobile drawer support.
* **Sticky Header Navigation**: Glassmorphic frosted backdrop (`backdrop-filter: blur(12px)`), working global search, date range filter, notifications dropdown, and user profile menu.
* **Spotlight Global Search (`Ctrl + K`)**: Instant search overlay indexing campaigns, clients, leads, tasks, and reports with one-click direct view navigation.
* **Notification Center**: Dropdown drawer with unread counters, notification dismissal, and "Mark all read".
* **Quick Add Menu**: Universal modal launcher for creating Campaigns, Clients, Leads, Tasks, and Calendar Events.

### 2. 📊 Main Overview & Dynamic KPI Center
* **8 Animated KPI Cards**:
  1. Total Revenue (`$248,560`)
  2. Campaign Spend (`$72,840`)
  3. Leads Generated (`18,426`)
  4. Conversion Rate (`8.64%`)
  5. Average ROI (`3.42x`)
  6. Active Campaigns (`24`)
  7. Client Accounts (`86`)
  8. Qualified Leads (`7,248`)
* **Time Period Selector**: Toggle between `Today`, `7 Days`, `30 Days`, `90 Days`, and `Custom` to see dynamic recalculations across the workspace.
* **High-Precision Canvas Charts**: Pure HTML5 Canvas 2D area/line charts with smooth quadratic bezier curves, multi-color glowing strokes, gradient fills, and period filters (`7D`, `30D`, `90D`, `1Y`).
* **Attribution Progress Bars**: Real-time channel breakdowns for Google Ads, Meta Ads, LinkedIn, SEO, and TikTok.

### 3. 🚀 15 Dedicated Agency Management Views
1. **Overview**: Executive high-level performance snapshot, charts, attribution, and live campaign snapshot.
2. **Campaigns**: Full campaign table with budget utilization bars, status badges (`Active`, `Paused`, `Review`, `Completed`), and working `Edit`, `Pause/Resume`, and `Delete` actions.
3. **Clients**: Portfolio cards displaying monthly spend, total ARR, account manager, health scores, and messaging shortcuts.
4. **Leads (CRM)**: Inbound lead pipeline with search, stage dropdowns (`New`, `Contacted`, `Qualified`, `Proposal`, `Won`, `Lost`), deal values, and modal editors.
5. **Analytics**: Deep-dive marketing intelligence including full-funnel conversion velocity and Customer Acquisition Cost (CAC) vs. Lifetime Value (LTV) chart.
6. **Social Media**: Cross-network audience metrics for Instagram, LinkedIn, TikTok, YouTube, Facebook, and X with top-performing creative rankings.
7. **SEO**: Domain authority indicator (`79/100`), organic traffic metrics, average ranking positions, and searchable Top Keywords table.
8. **Content**: Editorial calendar with format types (Blog, Video, Social, Ad Creative, Email), publication statuses, and live preview modal.
9. **Advertising**: Omnichannel paid media matrix detailing impressions, CTR, conversions, CPA, and net ROAS.
10. **Tasks**: Interactive 4-lane Kanban task board (`To Do`, `In Progress`, `Review`, `Completed`) with priority tags (`Urgent`, `High`, `Medium`, `Low`) and completed checkboxes.
11. **Calendar**: Interactive monthly grid for campaign milestones, client syncs, content drops, and ad deadlines with day-picker modal.
12. **Reports**: Pre-formatted executive intelligence reports with preview modal and client-side instant CSV download.
13. **Team**: Agency roster with project counts, task loads, ratings, and member management.
14. **Messages**: Functional live chat simulation with conversation threads, online indicators, message bubbles, timestamps, and realistic automated replies.
15. **Settings**: Theme switchers (Dark / Light), compact layout density toggle, agency metadata configuration, JSON backup export, and one-click demo data reset.

### 4. 💾 LocalStorage Persistence & Zero CDNs
* All campaigns, client accounts, leads, tasks, content, calendar events, notifications, chat messages, and theme preferences persist automatically in browser `localStorage`.
* Icons are rendered exclusively through lightweight inline SVGs.
* Zero external CSS frameworks (no Tailwind, Bootstrap, or FontAwesome dependencies).
* Completely usable offline without internet connectivity.
